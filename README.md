## Day 25 – Introduction to Node.js & Express.js
This project demonstrates the fundamentals of backend development using Node.js and Express.js. It includes creating a basic web server, implementing custom routes, and returning both text and JSON responses.

## Features
Express.js server setup
Custom GET routes
JSON API response
Understanding HTTP methods (GET, POST, PUT, DELETE)
Basic routing implementation

## Technologies Used
Node.js
Express.js
NPM

##Learning Outcomes
Understanding Node.js runtime environment
Working with NPM packages
Creating and running Express servers
Building REST API endpoints
Handling client requests and server responses
